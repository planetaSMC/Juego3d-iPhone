# V21.4 · 12 medicamentos, modo Extremo y penalización

Esta revisión amplía V21.3 con más variedad de colores, pedidos más rápidos,
un modo Extremo y una penalización clara al entregar el medicamento equivocado.

## 1. Doce medicamentos y colores

Se sumaron tres colores a los nueve existentes:

| Color | Medicamento |
|---|---|
| Rojo | Paracetamol |
| Azul | Ibuprofeno |
| Verde | Metformina |
| Amarillo | Diclofenac |
| Violeta | Omeprazol |
| Naranja | Amoxicilina |
| Celeste | Loratadina |
| Rosa | Losartán |
| Marrón | Naproxeno |
| Blanco | Salbutamol |
| Lima | Aspirina |
| Grafito | Calcio |

- Cada estantería habilitada tiene **cuatro grupos de color**, una fila por
  color: A rojo/azul/verde/amarillo, B violeta/naranja/celeste/rosa y
  C marrón/blanco/lima/grafito.
- Hay **12 estaciones**, una por color, repartidas entre las tres estanterías.
- El HUD y el bot usan el color sólido exacto del medicamento.

## 2. Clientes más rápidos

- Los tres clientes iniciales aparecen en 0,1 / 0,45 / 0,8 s.
- Después de una entrega, el siguiente cliente entra a los 0,35 s.
- La caminata hacia la fila y la salida son más rápidas; el cliente atendido
  se retira a los 0,9 s.
- La cola sigue limitada a tres clientes y sin superposiciones.

## 3. Modo Extremo

Se agregó una cuarta dificultad:

| Dificultad | Intervalo del bot | Velocidad |
|---|---|---|
| Fácil | 12 s | 0,75× |
| Normal | 9 s | 1× |
| Difícil | 6 s | 1,25× |
| **Extremo** | **3,5 s** | **1,7×** |

Extremo aparece en el menú y en Opciones con acento rojo. El bot empieza a
atender a los 1,2 s y no deja margen para errores.

## 4. Medicamento incorrecto: −1 punto

- Si el medicamento entregado no coincide con el pedido, se descuenta **1
  punto** (el marcador nunca baja de 0).
- El aviso dice **«Incorrecto · -1 punto»**; ya no se muestra «Correcto».
- El cliente vuelve a quedar pendiente, el hueco permanece y el pedido
  reaparece en el HUD para reintentar.

## 5. Reabastecimiento automático

- Cuando **todas las cajas de un color** de las tres estanterías habilitadas
  fueron consumidas (por ejemplo, ya no queda ningún remedio verde), la
  sección se reabastece sola.
- Las cajas vuelven a su hueco con una pequeña animación de escala y el stock
  de ese color se restaura a 8.
- El aviso muestra qué color se repuso.
- Solo se reabastece cuando no queda ninguna caja de ese color en la mano, en
  la cinta ni en la estantería; si todavía hay una en juego, espera.
